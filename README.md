# Hospital-Management-Analysis
Hospital Management Data Analysis using SQL and Power BI. This project analyzes patient records, appointments, admissions, doctor performance, revenue, and payment status. It includes data cleaning, SQL queries, DAX measures, interactive dashboards, and KPI visualizations to gain insights into hospital operations.

##  Project Overview
This project focuses on analyzing hospital data using SQL and Power BI to understand patient details, appointments, admissions, doctor performance, hospital revenue, and payment status. The goal is to transform raw data into meaningful insights that support better hospital management and data-driven decision-making.

##  Project Objectives
- Analyze patient registrations and appointment records.
- Evaluate doctor performance and department-wise appointments.
- Understand hospital admissions and room utilization.
- Analyze revenue and payment status.
- Create an interactive Power BI dashboard to visualize key performance indicators (KPIs).

## 🛠️ Tools & Technologies
- **MySQL:** Data querying and analysis.
- **Power BI:** Interactive dashboard creation and data visualization.
- **DAX:** KPI calculations and measures.
- **Power Query:** Data preparation and transformation.
- **Microsoft Excel / CSV:** Dataset storage and data handling.

##  Dataset Used
The project uses a hospital management dataset consisting of six CSV files:

- **Patients:** Patient demographics and registration details.
- **Doctors:** Doctor information, departments, experience, and consultation fees.
- **Appointments:** Appointment dates, types, and statuses.
- **Admissions:** Admission details, room types, and length of stay.
- **Medical Records:** Diagnoses, treatments, and medical notes.
- **Billing:** Billing amounts, service types, payment methods, and payment statuses.


##  SQL Analysis
SQL queries were used to analyze hospital operations, including:

- Top 10 doctors by appointment count.
- Department-wise appointment analysis.
- Top 10 doctors by revenue.
- Payment status and billing analysis.
- Top 10 cities by patient count.
- Most common diagnoses.
- Average, maximum, and minimum length of stay.
- Appointment status distribution.
- Monthly appointment trends.
- Admissions by room type.
- Billing analysis by payment method.
- Average consultation fees by department.
